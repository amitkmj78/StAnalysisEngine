01

Portfolio management

Multiple named portfolios per user, built up from a Robinhood CSV import or manual entry, priced live against the market rather than the last-saved snapshot.

multi-portfolioCSV import live pricingmargin

Multi-portfolio switching

Create, rename, switch between, and soft-delete separate portfolios (e.g. "Retirement" vs. "Trading") without losing history on delete.

Robinhood CSV import

Reconstructs open positions from raw activity history using an average-cost model, and extracts each position's real earliest-buy date from the file itself.

Manual entry with acquisition date

Add a position by hand with an optional "date acquired" — defaults to today, but a real past date is honored and preserved across every later save.

Stable "held since" dates

Every save (edit, refresh, CSV re-import) used to silently reset each position's acquisition date to today. Now carried forward permanently once set.

Live market value per position

Shares × current price, computed fresh on every load — not the value at last save — shown to 3 decimal places per holding.

Today's Gain/Loss

Standard day-P&L: current price vs. yesterday's close, after-hours-aware when the market is in a pre/post session.

After-hours-aware pricing

When Yahoo reports a pre- or post-market quote, portfolio value, gain/loss, and the price column all reflect it instead of the stale regular-session close.

30-day & cost-basis comparison

Every holding's value now vs. 30 days ago and vs. what was actually paid, independent of when the portfolio was last touched.

S&P 500 benchmark comparison

Portfolio return since creation and today's move, set directly against SPY — with a named, ranked list of the worst-performing holdings when trailing by a meaningful margin.

Sector-level concentration

Flags not just single-ticker concentration but a whole sector overweight spread across several holdings.

Portfolio Review

Deterministic flagging (SELL signal, concentration, sentiment/signal disagreement) synthesized into one readable summary — describes the data, never instructs a trade.

Margin balance & Net Equity

Record money borrowed against a portfolio; Net Equity (market value minus margin) appears automatically once margin is in use.

Build Diversified Index

Generates an equal-weight, sector-diversified basket of individual stocks from the top scorers per sector, with an optional cap on total holding count (round-robin across sectors, not a flat cutoff).

Compare vs. Best Fund

Sets a hand-built basket against the top-ranked comparable index fund.

Goal-Based Investing Plan

Signal-weighted allocation solved against a target dollar goal and timeline.

Portfolio Strategies cards

Short- and long-term plan per holding, blending the quant Signal with live sentiment so cards differentiate instead of reading identically across tickers. Collapsible for large portfolios.

02

AI price forecasting

A backtested quant forecast for one ticker at a time, shown next to how often the model has actually beaten doing nothing — the platform's post-login landing page.

Multi-horizon forecast

1-, 5-, and 10-day price projections with a confidence interval, plus a BUY/HOLD/SELL read derived from the same underlying number.

Safe Baseline Price Band

Floor/ceiling and typical accumulation/distribution zones from historical behavior — a different, complementary methodology to the point forecast.

AI narrative context

An LLM turns the model's own numbers into plain-English context — explains what the data shows, never invents a recommendation the model didn't produce.

Accuracy leaderboard

Tracks how each saved forecast actually performed once its target date arrived.

Live market context on the landing page

A scrolling market-news ticker and a "today's biggest winner/loser" widget, pulled from whichever portfolio was last open.

03

Quant signal vs. analyst rating

The model's own call next to real Wall Street analyst consensus — two independent reads, shown side by side rather than blended into one score.

Side-by-side comparison table

Quant BUY/HOLD/SELL and expected return against analyst buy-rating percentage and coverage count, for every captured ticker.

Signal history & stability

Tracks every signal flip over time, classifying each as a Chase (re-rating right after a big same-day move) or a Model shift (a genuine change in view).

Outcome-aware reasoning

When a prediction and the actual price move disagree, generates context using the real move since the signal was captured — never claims causation it can't support.

Reachable from Portfolio

Jump straight from any holding to its own quant-vs-analyst read, with a return link back.

04

Stock & fund screening

Composite ranking across configurable universes, for both individual stocks and index funds.

Stock Finder / Screener

Weighted composite score across return, technical, and fundamental metrics, ranked within a chosen universe (S&P 500, sector samples, or the full live index).

Live S&P 500 membership

The "All" and "S&P 500" universes resolve against the real, current constituent list rather than a stale hardcoded sample.

Fund Screener

Ranks existing index ETFs by category for investors who'd rather hold a fund than a hand-built basket.

Real analyst ratings on demand

Live third-party consensus and price targets fetched per ticker, not part of the bulk scan.

05

Momentum & backtesting

An honest, walk-forward test of the trailing-return ranking behind Top Performers — simulated day by day, never peeking at what happened next.

Rebalance windows
10 / 30 / 60 / 90d
Slippage
5 bps
History span
1–5 years

Event-driven simulation

A real day-by-day walk with explicit portfolio state, not a single bulk average — risk metrics are computed from the full daily equity curve.

Realistic trading costs

Slippage and commission applied on every rebalance by default; a real (currently zero, long-only) borrow-cost formula wired into the return chain.

Equal-weight benchmark

Every run is compared against simply owning the whole universe equally over the identical daily steps.

Capacity & turnover estimates

A conservative average-daily-volume ceiling on strategy size, plus average portfolio turnover per rebalance.

Persisted, re-fetchable runs

Every backtest is saved with its full parameter set and retrievable later by id, exactly as it was computed.

Resilient to a large universe

Downloads a 500+ ticker universe in paced batches, and excludes any constituent too newly listed to cover the requested window — so a recent spinoff can't silently shrink a multi-year test.

06

Market news & research

A self-hosted search index for curated finance sources, with licensed and free fallbacks.

Scrolling market news ticker

Broad market headlines from index/ETF bellwethers, shown on the Portfolio and Forecast pages; falls back to a plain web search when the primary feed is empty.

CrawlSearch — proprietary index

A standalone crawler and full-text index over a curated list of finance/news domains, respecting robots.txt and per-domain rate limits.

On-demand crawl trigger

Admins can start, watch live progress on, and stop a crawl across all or selected domains, without leaving the admin console.

Per-domain configuration

Page caps, crawl depth, politeness delay, sitemap use, and include/exclude filters, editable live per domain.

Licensed & free fallbacks

Falls through to a licensed search API, then a free scraping-based source, so research never depends on a single provider.

07

AI assistant

A conversational research agent that reasons over the platform's own live data.

Meta-agent orchestration

Routes a question to specialized basic, technical, and financial sub-agents and synthesizes their findings into one answer.

Consistent live pricing

Every agent answers from the same reliable live-price pipeline the rest of the app uses, instead of raw, occasionally-stale data feeds.

Provider fallback

Automatically retries on a second LLM provider if the first returns an empty or failed response.

08

Watchlist & alerts

Price-level alerts that stay in sync with each holding's own plan.

Auto-set watchlist alerts

Saving a position sets an upside target and stop by default, straight from its own short-term plan.

Drop alerts

Same-day drop detection per holding, with sentiment and quant-signal context folded into the notice.

Per-portfolio sensitivity

Drop-alert scanning can be silenced for a specific buy-and-forget portfolio without affecting any other.

09

Admin & operations

Operational tooling for keeping the platform, its data providers, and its users healthy.

Integrations dashboard

Lists every external dependency (LLM providers, market data, search) and runs a real live call on demand — configured and working are checked separately.

Price-provider switch

Toggles the live-quote source between providers without a deploy.

User management

Approval queue for new signups, deactivate/reactivate, force logout, and welcome email — plus last login date, time, and IP address per user.

Signal Stability panel

Every recent signal flip across all tickers, with the classification (boundary noise, chase, or model shift) explained inline.

Activity log & SQL runner

Full audit trail of admin actions, plus a guarded read query console for ad-hoc investigation.

Database backup controls

On-demand and scheduled backup management from the console.

Scheduler & quota controls

Enable/disable background jobs and per-endpoint daily usage caps without a code change.

10

Security & access control

Session handling and account safeguards for a multi-tenant, admin-gated platform.

Admin-gated signup

New accounts start pending; nothing is accessible until an administrator approves them.

Session-based auth

HTTP-only session cookie, with a bearer-token fallback for direct API use.

Real-time revocation

Deactivating a user or forcing a logout invalidates their already-open session within seconds, not just at next login.

Breach-checked passwords

New and reset passwords are checked against known-breach data via a k-anonymity API — the password itself is never transmitted.

Accurate login provenance

Last-login IP is captured from the real originating request, not an internal service hop.
